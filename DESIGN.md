# ContentOS design direction

ContentOS is an operate-first dashboard. Its visual world borrows from a carefully maintained workflow record: blue ink, ruled structure, compact operational density, and red marks reserved for review or risk.

- Ground: warm paper white with faint blue rules; ink: deep navy-blue; signal: restrained red; success: muted green.
- Typography: a humanist sans for interface copy, tabular monospace only for IDs, timestamps, and measurements.
- Composition: standard web app shell with a compact top bar, left navigation, workflow summary, task table, and detail rail.
- Signature move: a visible left-to-right execution trace that shows intake, planning, worker execution, validation, review, and approval as a connected sequence.
- Interaction: familiar buttons, tabs, filters, and panels. Task state is always readable in text and color.
- Responsive behavior: the detail rail moves below the task list; the execution trace becomes horizontally scrollable; tables preserve readable minimum widths.
